# Instituto Vetta - Backend

Backend desenvolvido para o sistema do **Instituto Vetta Profissionalizante**, uma instituição de cursos profissionalizantes. O projeto foi criado com o objetivo de fornecer uma API robusta e escalável para gerenciamento das informações da plataforma, integração com o website e suporte aos processos da instituição.

A aplicação é responsável pelo gerenciamento dos dados, comunicação com o banco de dados, processamento das regras de negócio e disponibilização de endpoints para consumo pelo frontend.

O objetivo do projeto é proporcionar uma estrutura segura e organizada para o Instituto Vetta, permitindo a administração de cursos, informações institucionais e funcionalidades necessárias para melhorar a experiência dos alunos e gestores.

## 🛠️ Tecnologias Utilizadas

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* REST API
* Maven

## 🎯 Objetivo

Criar uma API profissional, escalável e organizada para atender às necessidades do Instituto Vetta, garantindo uma base sólida para evolução da plataforma e integração com futuras funcionalidades.
